# Eski denemeler

Bu klasörde önceki projeden kalan, mevcut oyunda yüklenmeyen deneme dosyaları korunur.

- `game.js`: Phaser kullanmayan eski canvas denemesi.
- `anim.js`: Projede bulunmayan `assets/animations` dosyalarına başvuran animasyon örneği.

Bu dosyalar `index.html` tarafından çalıştırılmaz. İçlerindeki eski dosya yolları güncellenmemiştir.
